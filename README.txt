Iron Watch v1.6 — дневник тренировок для Android, работает без интернета

УСТАНОВКА ЧЕРЕЗ GITHUB PAGES (бесплатно, интернет нужен один раз)
1. github.com → войти/зарегистрироваться. Включи 2FA: Settings → Password and authentication.
2. «+» вверху справа → New repository. Имя: iron-watch. Public. Create repository.
3. В репозитории: «uploading an existing file» (или Add file → Upload files).
   Перетащи ВСЕ файлы из этой папки (index.html должен лежать в корне, не в подпапке). Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
5. Через 1–3 минуты вверху страницы Pages появится ссылка https://ИМЯ.github.io/iron-watch/
6. На телефоне открой ссылку в Chrome → меню ⋮ → «Добавить на главный экран» → «Установить».

ОБНОВЛЕНИЕ
Add file → Upload files → перетащи новые файлы (заменят старые) → Commit.
Открой приложение с интернетом, закрой и открой ещё раз — загрузится новая версия. Данные сохранятся.

ДАННЫЕ
Хранятся только в телефоне и привязаны к адресу сайта. Если адрес меняется (например, переезд с Netlify),
сначала сохрани копию: Профиль → Резервная копия → Скачать файл, потом загрузи её в новой версии.
