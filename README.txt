Iron Watch v1.16 — дневник тренировок для Android, работает без интернета

УСТАНОВКА ЧЕРЕЗ GITHUB PAGES (бесплатно, интернет нужен один раз)
1. На телефоне открой ссылку в Chrome → меню ⋮ → «Добавить на главный экран» → «Установить».

iPHONE
Открой ссылку в Safari → кнопка «Поделиться» (квадрат со стрелкой вверх) → «На экран „Домой“» → «Добавить».
Пользуйся только иконкой: у приложения с главного экрана свои данные, отдельно от вкладки Safari.

ОБНОВЛЕНИЕ
Add file → Upload files → перетащи новые файлы (заменят старые) → Commit.
Через 5–10 минут после публикации открой приложение с интернетом — новая версия загрузится сама
(или Профиль → О приложении → «Проверить обновление»). Данные сохранятся.

ДАННЫЕ
Хранятся только в телефоне и привязаны к адресу сайта, сначала сохрани копию: Профиль → Резервная копия → Скачать файл, 
потом загрузи её в новой версии.
